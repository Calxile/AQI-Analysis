# AQI Analysis

A machine learning project to analyze and predict Air Quality Index (AQI) using environmental features like pollutant levels and weather conditions - built with PySpark and Scikit-learn.

## Files
- AQI.ipynb - Main notebook

## Dataset
The AQI dataset contains the following files:
- city_day.csv - Daily AQI data by city
- city_hour.csv - Hourly AQI data by city
- station_day.csv - Daily AQI data by station
- station_hour.csv - Hourly AQI data by station
- stations.csv - Station metadata

## Tech Stack
- Python 3.x
- Apache Spark (PySpark)
- Pandas, NumPy
- Scikit-learn
- Matplotlib / Seaborn
- Jupyter Notebook
